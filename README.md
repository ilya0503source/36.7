# 36.7
Это версия сервера чата

В данном приложении реализованы функции:
1. Запуск сервера (для этого необходимо в запущенном приложении нажать "Меню - Сервер> Сервер - Старт")
2. Остановка сервера (для этого необходимо в запущенном приложении нажать "Меню - Сервер> Сервер - Стоп"), при этом клиенту отправляется служебаня команда на закрытие клиентского приложения, выполняется завершение сеансов связи, приложение Чат - Сервер закрывается
3. Бан пользователя (необходимо нажать правой кнопкой мыши по пользователю в списке пользователей и выбрать функцию "Забанить"), в результате пользователь будет забанен и отключен от сервера, авторизация пользователя будет невозможна до разбана.
4. Разбан пользователя (необходимо нажать правой кнопкой мыши по пользователю в списке пользователей и выбрать функцию "Разбнить"), в результате метка бана у пользователя снимается, пользователь может авторизоваться на сервере.
5. Отключение пользователя (необходимо нажать правой кнопкой мыши по пользователю в списке пользователей и выбрать функцию "Отключить"), в результате произойдет отлючение выбранного пользователя от сервера, приложение клиента закрывается.
6. В области "Все сообщения:" выводятся все сообщения которыми обмениваются пользователи
7. При запуске Сервера чата создается аккаунт администратора (логин: admin, пароль: admin), зайти под этим аккаунтом возможно из клиентской части приложения.
8. Реализована функция логгирования служебных сообщений: они выводятся в статус бар главного окна, а также сохраняются в текстовый файл LOG/log.txt рядом с расположением исполняемого файла
9. Перед закрытием приложения "Чат - Сервер" необходимо выполнить функцию "Меню - Сервер> Сервер - Стоп" для корректного отключения пользователей
