# 36.7
Это версия клиента чата

Подключение выполняется по умолчанию в ip:localhost port:12345 (однако в случае если сервер будет запущен на другом ip или port то настройки возьмутся из файла "config.ini" (файл должен быть расположен рядом с исполняемым файлом)

В приложении реализованы функции:
1. Авторизация
2. Регистрация
3. Отправка сообщения всем (для этого необходимо ввести текст в поле "Ваше сообщение:" и нажать кнопку "Отправить всем" или клавишу "Enter" на клавиатуре.
4. Отправка личных сообщений (для этого необходимо ввести текст в поле "Ваше сообщение:" и нажать кнопку "Отправить лично", затем выбрать пользователя из списка двойным кликом левой кнопки мыши)
5. Пароль отправляется на сервер в захэшированном виде
